# Lamborghinirevuelto Highway Dash

Faz um jogo de toques, aonde uma Lamborghini revuelto, anda pela rodovia correndo, o jogo é em pé. Apertando o acelerador o carro corre apertando o freio o carro freia e nos dois cantos da tela esquerda e direita é pra virar, e se bater o carro bate sai fumaça e aparece game over e botão de reiniciar... A Lamborghini revuelto você sabe como é né? Faz uma Lamborghini revuelto preta
